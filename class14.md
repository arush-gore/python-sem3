# continue
- Terminates the execution in the current iteration and continues for execution of the loop with the next iterations.

```python
i=1
while i<10:
    if i ==5:
        i+=1
        continue
    print(i)
    i+=1
```
 A for loop is used for *iterating over a sequence (that is either a list, a tuple, a dictionary, a set or a string).
 This is less like the **for a keyword** in other programming languages and works more like an **iterator method** as found in other object-orientated programming langagues.
 With the for loop, we can execute a set of statements, once for each item in a list, tuple, set, etc.
 break statement: we can stop the loop before it has looped through all the items
 continue statement: we can stop the current iteration of the loop and continue with the next:
